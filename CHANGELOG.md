# OCGoQuota Changelog

## v2.0.0

- Android-only Tauri 2 application for OpenCode Go quota and usage tracking.
- Local Rust + SQLite core with encrypted Cookie storage in the app-private data directory.
- Resumable account synchronization, quota windows, token rankings, daily trends, and usage records.
- Android 9+ support with arm64 APK packaging and signed GitHub Actions release artifacts.
- Rebranded from 68HUB to OCGoQuota with a new application icon.
